# WebSocket /ws stream (QMI8658 polled on core 1, broadcast per sample): accel + gyro + temperature.
#   102 frames in 2 s  (~51 Hz, matching poll(hz: 50))
#   {"ax":0.029,"ay":0.039,"az":-0.995,"gx":-3.1,"gy":2.2,"gz":-0.1,"t":38.2}
#   at rest: az ~ -1 g (gravity), gyro ~ 0, chip temp ~ 38 C -> real data.
#   (accel/gyro come from the core-1 ring; temperature is read ~5 Hz and folded into every frame.)
#
# A 20 Hz timer (every(50, StreamTick)) broadcasts the latest sample, decoupled from the 50 Hz core-1
# poll. Steady under load -- WS stream + 15 concurrent GET /:
#   idle rate:       20 Hz
#   under-load rate: 20 Hz   (unchanged)
#   GET / during stream: 15/15 -> 200
# ws_broadcast() also sends non-blocking (select-guarded): a slow client is skipped, never stalls the
# reactor. No "reactor queue full", no lag.
#
